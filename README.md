本仓库包含 A 题从**数据读取 → 机理建模 → 数值求解 → 多方法检验 → 灵敏度分析 → 模型评审**的全过程代码、

## 1 问题与主要结果

| 问题 | 内容 | 结果 |
|---|---|---|
| 问题 1 | 预热平衡阶段（0—1800 s）温湿度分布（附录 2 常物性） | 1800 s 时温度 **33.5758（中心）→36.7858 °C（表面）**；含水率 **2.5500→1.5102 kg/kg**（内部基本不动） |
| 问题 2 | 全过程（2—3 天）变物性模型（附录 3） | 3 h 时温度 **49.85—49.97 °C**（近等温）；含水率 **1.7662（中心）→1.0081（表面）** |
| 问题 3 | 按"各处含水率 < 0.15 kg/kg"确定烘干时长 | **57.1471 h ≈ 2.38 天**（205 729 s） |
| 问题 4 | 考虑尺寸收缩（附件 2 + 附录 4）确定烘干时长 | 基线（仿射收缩）**50.8119 h ≈ 2.12 天**；**v2 非均匀收缩模型 47.6208 h ≈ 1.98 天** |

> **问题 4 的两个合规答案**：只用附件 2 的整体半径（均匀/仿射收缩）得 **50.81 h**；
> 若再用附录 4 的密度式给出**局部**收缩的相对分布（以附件 2 整体标定）得 **47.62 h**，两者相差 6.3 %。
> 专题说明见 [`docs/问题4收缩建模两条路线的说明.pdf`](docs/问题4收缩建模两条路线的说明.pdf)。
>
> **版本说明**：v1 见 [`docs/…建模与求解说明文档.pdf`](docs/药材烘干问题A题_建模与求解说明文档.pdf)；
> **v2（推荐，含题目复核 + 三项改进）**见 [`docs/…_v2.pdf`](docs/药材烘干问题A题_建模与求解说明文档_v2.pdf)。

**核心物理判读**：热扩散特征时间 $R^2/\alpha\approx39$ min、水分扩散特征时间 $R^2/D_0\approx22.7$ h，
两者相差 35 倍——这决定了几何上"温度 30 min 内即可显著穿透、水分却只在表层变化"。
后期干燥由 $D(C)$ 随含水率急剧衰减支配（$C:0.5\to0.15$ 时 $D$ 减小约 7 倍），呈指数拖尾，故烘干时长为 2—3 天量级。

### 2.1 三项关键决策

| # | 决策 | 依据与代价 |
|---|---|---|
| 1 | **一维轴对称简化**（长径比 25/4 = 6.25） | 另建二维轴对称模型（含 12.5 cm 半长端面）验证：中心点相对偏差 **< 0.5 %**，端面影响仅波及距端面约 2 cm（§9.5） |
| 2 | **问题 4 用材料(Lagrangian)坐标**而非直接对空间方程作坐标变换 | 直接变换会多出附加对流项并使水分**非物理增加**（中心含水率反升到 3.66，烘干时长被拉长到 99.2 h）；本文从干物质守恒推导，水分严格守恒（审计残差 $1.2\times10^{-5}$）（§8.3） |
| 3 | **恒温阶段边界常值延拓**（$T_\infty=50.165$ °C、$C_\infty=0.04986$ kg/kg） | 附件 1 只覆盖 4 h；敏感性分析表明 $C_\infty$ 在 0.02—0.12 变化时烘干时长仅 −1.0 %—+16.8 %（§9.6） |

### 2.2 烘干时长敏感性（问题 3，基准 57.15 h）

| 变动因素 | 取值范围 | 烘干时长 / h | 相对基准 |
|---|---|---|---|
| 恒温阶段温度 $T_\infty$ | 45.0 / 50.165 / 55.0 °C | 67.62 / 57.11 / 49.24 | **+18.4 % / 0 / −13.8 %** |
| 烘房湿度 $C_\infty$ | 0.02 / 0.04986 / 0.12 | 56.54 / 57.11 / 66.70 | −1.0 % / 0 / +16.8 % |
| 对流传质系数 $k_m$ | ×0.8 / ×1.2 | 58.82 / 56.06 | +3.0 % / −1.9 % |
| 对流换热系数 $h$ | ×0.8 / ×1.2 | 57.13 / 57.09 | +0.03 % / −0.02 % |

**结论**：烘干时长由**烘房温度控制**主导（$D\propto e^{-3850/T}$），对 $k_m$、$h$、$C_\infty$ 相对稳健；
模型形式（守恒/非守恒）与物性公式（附录 3/附录 4）影响最大，必须严格按题目要求分问题选取。

## 4 复现步骤

环境：Python 3.12 + NumPy / SciPy / OpenPyXL / Matplotlib（无随机性，重跑结果**逐位一致**）。

```bash
cd work/src
PY=python3        # 需 Python 3.10+，含 numpy/scipy/openpyxl/matplotlib

# ---- 生产计算：问题 1—4 → outputs/result_files/result1—4.xlsx（约 2 分钟）----
$PY run_production.py

# ---- 检验套件（对应说明文档 §9.1—§9.6）----
$PY verify_01_analytical.py         # A 解析解（贝塞尔级数）对比
$PY verify_02_mol_conservation.py   # B 网格/时间步收敛  C 独立方法(MOL+BDF)  D 守恒审计
$PY verify_03_2d_axisym.py          # E 二维轴对称（验证一维假设）
$PY verify_05_sensitivity.py        # F 参数与模型形式敏感性
$PY verify_04_p4_audit.py           # 收缩域守恒专项审计

# ---- 最终校核 ----
$PY final_check_drytime.py          # N=800 高分辨率复核烘干时长
$PY final_check_consistency.py      # 文档表格 ↔ result*.xlsx 逐格比对

# ---- 出图与表格 ----
$PY make_figures.py                 # 图 1—8 → outputs/figures/
$PY make_tables_md.py               # 表格片段 → work/out/tables.md
```

说明：

* `work/out/*.npz`（约 116 MB 的场数据缓存）未纳入版本库，运行 `run_production.py`（约 2 分钟）即可生成，
  随后检验与绘图脚本可直接运行；
* 仓库已包含全部**结果留档**：`outputs/result_files/result1—4.xlsx`、`outputs/figures/` 与
  `outputs/tables/`（关键结果表 + 全部检验 JSON），无需重算即可查阅所有数字。

## 5 检验证据（摘要）

| 检验 | 结果 |
|---|---|
| A 解析解（圆柱对流边界贝塞尔级数） | 含水率最大误差 $1.47\times10^{-4}$（$N=400$）→ $9.0\times10^{-6}$（$N=1600$），**二阶收敛** |
| B 网格收敛 | $e(200)/e(400)=5.03\approx4$（二阶）；时间步细化 16 倍仅变化 $4.0\times10^{-7}$ |
| C 独立方法（单元中心 FV + 自适应 BDF） | 与主求解器：中心含水率偏差 $\le4.6\times10^{-5}$、表面 $3.0\times10^{-5}$、总水量 $2.7\times10^{-8}$ |
| D 守恒审计 | 定域 $7.1\times10^{-6}$（平均）；收缩域 $1.2\times10^{-5}$；初值总水量与解析值一致到 $10^{-15}$ |
| E 二维轴对称 | 中心点偏差 $<1.5\times10^{-3}$（相对 <0.5 %），与二维粗网格自身误差同量级 |
| F 敏感性 | 见 §2.2；对 $k_m,h,C_\infty$ 稳健（<5 %），温度主导 |
| 最终校核 | $N=800$ 复核：问题 3 = 57.1620 h（+0.026 %）、问题 4 = 50.8198 h（+0.005 %）；文档表格与结果文件逐格比对偏差 $0.00\times10^{0}$ |
| 非均匀收缩网格收敛（v2） | $N=200/400/800$：47.6131 / 47.6208 / 47.6230 h（≤0.02 %） |
| 二维含端面复核（v2） | 中心点偏差 <1 %；端面影响仅 $z>10$ cm，不控制达标时刻 |
| 环境数据平滑（v2） | PCHIP 57.108 h vs Savitzky–Golay 57.405 h（0.5 %） |
| 能量审计（v2） | 表面对流供热 $8.5\times10^{4}$ J vs 蒸发潜热需求 $5.8\times10^{6}$ J（约 70 倍差） |
| 工艺优化（v2） | CPLEX MILP：最优调度 PDE 复核 46.75 h、能耗代理 −6.0 %（预算 50 h） |

反例检验（用于论证建模决策）：若问题 4 采用"直接对空间扩散方程作 $\xi=r/R(t)$ 变换"的非守恒写法，
水分会被非物理制造（中心含水率 2.55 → 3.66 @10 h），烘干时长虚增至 **99.23 h**（正解 50.82 h）。
