## 可删除性 / 替换性

删除本目录不影响代码运行：`work/src/herb_model.py` 会按以下优先级定位附件目录

1. 环境变量 `CUMCM_DATA_DIR`；
2. `<repo>/data/附件`（本目录）；
3. `<repo>/data`。

```bash
# 使用其他位置的附件
CUMCM_DATA_DIR=/path/to/附件 python3 run_production.py
```

数据读取完全由 `openpyxl` 直接完成，未做任何人工转录——这也是全部结果可逐位复现的前提之一。
