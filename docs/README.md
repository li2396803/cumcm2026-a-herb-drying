## 最优性与正确性证据

* **解析解**：线性化问题与圆柱对流边界贝塞尔级数解对比，网格加密二阶收敛（$1.47\times10^{-4}\to9.0\times10^{-6}$）；
* **独立方法**：另写单元中心有限体积 + 调和平均面系数 + 自适应 BDF（SciPy）求解器，中心含水率偏差 $\le4.6\times10^{-5}$；
* **守恒性**：水分守恒审计残差 $10^{-5}$ 量级（定域与收缩域分别按各自正确的守恒度量核算）；
* **维度检验**：二维轴对称（含 12.5 cm 端面）与一维模型中心点偏差 <0.5 %；
* **最终校核**：$N=800$ 复核两个烘干时长偏差 ≤0.026 %，文档表格与结果文件逐格比对偏差 0。
