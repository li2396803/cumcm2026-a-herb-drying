## 模型检验摘要

| 检验 | 关键指标 | 结果 |
|---|---|---|
| A 解析解（贝塞尔级数） | 最大绝对误差（$N=400$，$\Delta t=1$ s） | 含水率 $1.47\times10^{-4}$；温度 $6.17\times10^{-5}$；加密网格二阶收敛 |
| B 网格/时间步收敛 | 误差比、时间步敏感性 | $e(200)/e(400)=5.03\approx4$（二阶）；时间步细化 16 倍偏差 $4.0\times10^{-7}$ |
| C 独立方法（单元中心 FV + BDF） | 中心/表面含水率偏差 | 问题 1：$1.1\times10^{-5}\sim2.6\times10^{-4}$；问题 3：$\le4.6\times10^{-5}$ |
| D 守恒审计 | 相对残差（平均 / 99 % 分位） | 问题 3：$7.1\times10^{-6}$ / $1.3\times10^{-4}$；问题 4：$1.2\times10^{-5}$ / $2.0\times10^{-4}$ |
| E 二维轴对称 | 中心点相对偏差 | $<0.5\%$（端面影响仅波及距端面约 2 cm） |
| F 参数与模型形式敏感性 | 烘干时长变化 | 温度 $\pm5$ °C：$-13.8\%\sim+18.4\%$；$k_m\pm20\%$：$\pm2\sim3\%$；$h\pm20\%$：$<0.05\%$；$C_\infty$ 0.02—0.12：$-1.0\%\sim+16.8\%$ |
